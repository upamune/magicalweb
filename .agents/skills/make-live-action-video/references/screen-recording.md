# 画面録画×マイク収録の回

ブラウザなどで資料を映しながらふたりが話す回。#296（動画編集のやり方回）で使った作り方。
映像は画面録画1本、音声は別録りマイク。人物が映らないので顔ぼかしの工程は通らない。
数値は#296の実績であり、新しい回では素材で測り直す。#296の制作記録は`/Users/upamune/Desktop/20261020/2026_1019_1943/out/README-296.md`、実装は同じフォルダの`work/`にある。

## 素材の確認

- 画面録画の音声トラックの中身を先に測る（`volumedetect`など）。#296の画面録画（1664×1080/60fps）は音声トラックがあるのに全編無音だった。
- 画面録画の有効領域を測る。#296は下32pxが黒帯で、有効領域は1664×1048だった。
- 録画の始めと終わりの数フレームが乱れる（一瞬黒くなる・ずれる）ことがある。フレーム差分で位置を記録しておく。

## 同期

画面録画に音があれば、通常どおり音声で照合する。無音なら**内容のアンカー**で合わせる。

1. 画面録画を0.5秒刻みの縮小フレームにし、フレーム差分からスクロールの開始時刻を拾う（#296の`work/motion.py`）。
2. 文字起こしから、画面を指す発話（「これですね」「後半がこの画面にあるやつ」など）の開始時刻を拾う。
3. 対応する組を離れた位置で6点ほど集め、`マイク = 画面 + オフセット`を1つに決める。各点の残差を`sync-anchors.json`に記録する。#296は14.49秒、残差は−0.6〜+1.4秒だった。
4. 手拍子と録画開始時の乱れ、両方の録画の終わりなど、独立した手がかりで裏付ける。

誤差は±1秒程度残る。静止したページのスクロールなら気にならないが、ユーザーには同期の方法と限界を伝え、スクロール箇所の短いプレビューで確かめてもらう。

## 冒頭

収録前のやりとり（「録画開始」「せーの」、手拍子）は外し、名乗りの直前から始める。#296は名乗りが編集時刻1.5秒に来るよう切り、OPは#295と同じく声の下に小さく流した。
編集時刻0と画面録画のフレームの対応（#296は編集フレームn＝元の60fpsフレーム`2n+1398`）を制作記録に残す。

## 画面の加工

ユーザー指定: ブラウザの枠（タブ・URLバー）は映さない。URLは公開したくない情報になりうる。
配置の案は、先に静止画で並べて見せる。

- 枠の下端は、複数の時刻で画面上部の明るさの行を調べて決める。#296は上端から75px付近で、`crop=1664:972:0:76`にした。ページ側の帯（「コンテンツはユーザーが作成したもので、未検証です。」など）はページの一部なので、スクロールすると消える。
- 高さ1080いっぱいに拡大し、左右の余白はデザイントークン`ink`（#1D1A2E）で埋める。テロップは画面の上に重ねる。
- 60fpsから30fpsへの間引き、切り取り、拡大、余白、乱れたフレームの差し替え（`freezeframes`）を1回のffmpegで行う。#296の`work/screen/render_screen_b.sh`。約35分の素材で約13分かかった。
- `freezeframes`は入力を2つ取るので、`-filter_complex`で`split`して渡す。
- `tpad=stop_mode=clone`では尺が伸びなかった。画面録画がマイクより先に止まる分は、最終フレームを`select=gte(n\,N),loop=loop=K:size=1:start=0`で繰り返した短い動画を作り、`concat`の`-c copy`で足す。PNGから作ると明るさがずれる（YAVG 169.7と171.6）ので、YUVのフレームから作る。
- 足した後で、総フレーム数、全編デコード、つなぎ目の前後の明るさを確かめる。

## テロップ・Resolve・検査

テロップは[audio-and-telops.md](audio-and-telops.md)のとおりに作る。#296は画面を指す発話が多く、「これですね」なども画面の説明として残した。
Resolveの組み立てと検査は[resolve-and-delivery.md](resolve-and-delivery.md)のとおり。構成は画面録画1本、固定テロップ、マスター音声の3つだけで、Classic区間はない。
#296の`work/resolve/`のスクリプトは版を引数で受け取る（`build_fcpxml.py v2 <画面> <音声> <ffconcat>`、`create_project.py v2 <日付>`、`render_preview.py --version v2`、`render_final.py v2`）。新しい回では尺・話数を書き換えて使う。

人物は映らないが、画面に映る情報（URL、通知、別のウィンドウ、アカウント名）は全編で確認する。`privacyReview`にはその確認範囲を書く。
