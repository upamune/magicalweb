## 冒頭ハイライト

OPだけが流れる冒頭は、ユーザーが別の指定をしない限り、タイトルカードではなく映像ハイライトにする。
最初の「静かなOPに綺麗な映像が並ぶだけ」の約4秒は「味気ない、YouTubeっぽくない」と差し戻された。

1. 静止区間を先に測る。この形式のvideo.mp4は再生を一時停止したまま話す区間が多く、#293では約65%が静止画だった。縮小グレースケールのフレーム差分で、静止フレームが0の区間だけを候補にする。
2. 「ちょっと待って！」カードと重なる区間、場面の切り替えをまたぐ区間を除く。動く区間をサムネイルで並べてカットを選ぶ。映える場所（#293では王宮の各部屋）を多めにし、料理などの静止したカットばかりにしない。
3. OPのアクセントを解析し、その拍でカットを切り替える。#293は13.8秒・12カット。
4. 等倍で切り替えるだけにする。ズームと早回しはユーザーが外す指定をした。白フラッシュ、黒からのフェードイン、最後のホワイトアウトから本編へのつなぎは承認済み。
5. ハイライト中はOPを上げる（#293は+8dB）。会話全体をハイライトの尺だけ後ろへずらし、最初の声から約0.6秒でOPを声の下の音量へ下げ、曲末へフェードする。全体のLUFSとTrue Peakを測り直す。
6. 字幕・場所ラベル・カード回避など、編集時計に乗る全素材を同じフレーム数だけずらす。Resolveでは前のタイムラインと比べ、全クリップが正確に+Nフレームであることを照合する。

全編を書き出す前に、ハイライト単体（OPの音つき、約14秒）をffmpegで書き出して見せる。承認後にResolveへ組み込み、ハイライトのクリップ以外が前のタイムラインと一致することを照合してから全編を書き出す。

#293の実装は`work-293/highlight-v2/render_highlight.py`と`plan-v2e.json`。各ショットに`sourceFrame`、`frames`、`speed`、`zoom`、`flash`、`fadeFrom`、`fadeTo`を持つ。30fps固定の書き方なので、別のfpsでは直してから使う。出力はBT.709のProRes 422 HQ。

## ハイライト中のタイトル

デザイン案は、まず静止画で複数パターンを並べて見せる。
隅に小さく出す案（場所ラベルと同じeditorial系）と、中央に大きく出す案の両方を作る。
明るい背景・暗い背景・柄の多い背景の実フレームに重ねた一覧画像にする。

承認された形（K: center-stacked）:

- 上に小さく`SPAIN × FRANCE`、中央に大きく旅の名前、下に黄色の部名チップと`#<話数> <都市名>`。
- 小さい文字の背後に薄い暗がりを敷き、明るいカットでも読めるようにする。
- 冒頭から30フレームでフェードインし、最後のホワイトアウトまで出し続ける。途中のアクセントで出す案は「後半すぎる」と差し戻された。

実装はリポジトリの`video/src/episode/HighlightTitle.tsx`で、Compositionは静止画の`HighlightTitleAsset`とアルファ付き動画の`HighlightTitle`。上の小さい文字は`kicker`で渡す。書き出し方は`video/docs/hybrid-episode-video.md`にある。アルファ付きProResで書き出し、ハイライトへ合成する。
正式タイトルが未定なら仮の文字だと伝える。決まったらハイライトだけ差し替えて書き出し直す。

## サムネイル

ユーザーの方針は「これまでと違う、YouTubeらしく見てもらえるサムネイル」。被写体をステッカーのように切り抜いて散らす。
承認された型（T1: ステッカー爆弾）:

- 背景に本編の写真。巨大な白と黄色のデカ文字に濃紺の太いフチ。
- 料理・建物・小物を切り抜いたステッカー（白フチ、細い濃紺の線、影）を散らす。
- 2人のドット絵アイコンもキャラの形に切り抜いてステッカーにし、吹き出しを付ける。
- 左上に`#<話数>`とシリーズ名・部名。1280×720、アップロード用JPGは2MB未満。

素材は、字幕の焼き込みがない顔ぼかし済みの映像から取る。人の顔を避けて料理・建物・小物を選ぶ。
切り抜きはローカルのApple Vision前景マスクで行い、外部へ送らない（macOS 14以降）。

```sh
swiftc -O SKILL_DIR/scripts/lift_subject.swift -o /absolute/work/thumb/lift
/absolute/work/thumb/lift frame.png /absolute/work/thumb/lifted/name
uv run SKILL_DIR/scripts/stickerize.py /absolute/work/thumb/lifted/name-i1.png /absolute/work/thumb/stickers/name.png
```

`lift`は前景のインスタンスごとの`-i<N>.png`と、全体の`-all.png`を書く。要らない手や腕が残ったら、ステッカー化の前に消す。
デカ文字と吹き出しのコピーは、本編で実際に話している内容か、RSSの概要・タイトルから取る。映像から推測した料理名などは、確認事項として伝える。缶のキャラクターなど目立つ他者の版権物が写っていたら伝える。

案は4つ前後を一覧にし、YouTubeの一覧表示に近い横360pxへ縮めた画像でも読めるかを見せる。
実装はリポジトリの`video/src/episode/Thumbnail.tsx`（Composition `Thumbnail`）で、T1だけを持つ。背景・デカ文字・ステッカー・吹き出しの配置をpropsで渡し、回ごとの画像は`--public-dir`の素材フォルダから読む。2人のアイコンは`video/public/thumbnail/`にあり、素材フォルダへ`thumbnail/`ごとコピーする。書き出し方とpropsの例は`video/docs/hybrid-episode-video.md`と`video/src/Root.tsx`。実装を変えたら、既存のサムネイル（#293、#290〜#292）を画素単位で比べて変わっていないことを確かめる。
モロッコ編（#290〜#292）も同じ型で作った。出力は`/Users/upamune/src/tries/2026-09-28-morocco-vlog/out/final-deliveries/`。

## LISTEN用の文字起こし（VTT／SRT）

LISTENの「文字起こしをアップロード」は、開始・終了時刻付きのVTTかSRT（UTF-8、10MB以下）を受け付ける。アップロードすると全文と時刻が置き換わり、チャプターとサマリーは残る。

時刻は、LISTENに上げた音声の時計に合わせる。冒頭にハイライトを足した動画と、LISTENの音声とでは時計がずれうるので、どの音声に合わせるかを確認する。
#293は動画v4と同じ時計にした。字幕データはハイライト挿入前の時計だったため、一律に+294フレーム（9.8秒）ずらした。

- VTTは話者を`<v みちるだ>`の話者タグで付ける。SRTは各行の先頭に`みちるだ：`を付ける。VTTを先に勧め、話者がうまく出なければSRTを試してもらう。
- 時刻の昇順と重なりがないことを検査する。
- 中身は画面用に整えた字幕であり、逐語の文字起こしではないこと、音声確認が残るページ数を伝える。

成果物をDesktopに置くよう頼まれることが多い。コピーする前に同名ファイルがないことを確かめ、コピー後に元ファイルと中身を照合する。
